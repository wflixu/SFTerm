## 1. 一句话定位

**macOS 上一个 SSH 与 SFTP 客户端：每个主机一个终端标签；SFTP 左边本地、右边远端，拖一下就传完。**

## 2. 顶层结构

```
┌──────────────────────────────────────────────────────────────────────┐
│ 🏠 Home │ 🗂 SFTP │ web-1 × │ db-2 × │  +      ⚙                      │
├──────────────────────────────────────────────────────────────────────┤
│ SFTP 页（未绑定）：                                                  │
│ ┌──── Local ────────────────┐ ┌──── (空状态) ────────────────────┐   │
│ │ Name  Date Modified Size  │ │        [64×64 图标]              │   │
│ │ 📁 Users                  │ │        Connect to host           │   │
│ │ 📁 lixu                   │ │   从一台已保存的主机开始…        │   │
│ │ …                         │ │       [ 选择主机 ]               │   │
│ └───────────────────────────┘ └──────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────┘
```

| 区域 | 规则 |
|---|---|
| 顶层标签 | `Home`（第 1）、`SFTP`（第 2）常驻不可关；连接标签可关；全部关完回到 Home |
| Home | 自带侧栏 + 内容区（§3） |
| SFTP 页 | 双栏，右栏未绑定时为空状态；选择主机后**原地绑定**（§2.1） |
| 连接页 | SSH 终端（独立 SSH 连接），不是文件页 |
| 终端页 | xterm 全区域 |
| 设置 | 顶层标签栏最右 ⚙，sheet 打开；`假设`（0.1.0 未实现） |

### 2.1 SFTP 常驻页

**未绑定状态**

- 左栏：本地文件，默认 `~/`，立即可用。
- 右栏：居中空状态
  - 图标：64×64，圆角 16，浅灰底，文件夹线稿
  - 标题：「连接主机」
  - 副标题：「从一台已保存的主机开始，用 SFTP 管理文件」
  - 按钮：「选择主机」（次要样式）
- 分隔条：垂直，默认 50/50。

**选择主机**

- 点击「选择主机」→ **popover**（不是 sheet）：搜索框 + 主机列表（最近连接置顶）+ 底部「前往 Hosts」。
- 选中后右栏**原地绑定**该主机：显示远端文件，面板头显示主机名，底部状态栏显示连接信息。
- 绑定后面板头提供「断开 / 终端 / 切换主机」；断开后回到空状态。
- 标签标题**保持 `SFTP`** 不变（常驻标签改名会让人找不到入口），主机名显示在右栏面板头。
- **0.1.0 现状**：选择主机是 440px 的模态对话框（不是锚定 popover），带搜索；没有「最近连接置顶」，也没有「前往 Hosts」入口。

**与 Home 的关系**

- Home 双击主机 → 打开（或切到）该主机的 **SSH 终端标签**，不改变 SFTP 页的绑定。
- 要传文件时切到 SFTP 页：已绑定同一主机则直接可用，否则「选择主机」。
- SFTP 页同一时刻只绑定一台主机；切换即替换，原连接在该主机没有其它使用者时关闭。

### 3.1 侧栏

| 项 | 图标 | 徽标 | 一期 |
|---|---|---|---|
| Hosts | 服务器 | 主机数 | 完整 |
| Keychain | 钥匙 | 密钥数 | 完整 |
| Snippets | 终端命令 | — | 空状态 |
| Logs | 列表 | — | 空状态 |

- 选中态圆角填充，悬停浅色填充。

### 3.2 Hosts

**卡片**

- 网格 `minmax(260px, 1fr)`，间距 16，内边距 48×32。
- 内容：服务器图标、主机名、`user@host:port`（灰字）、状态点（未连接 / 连接中 / 已连接）。
- 右上角：铅笔（编辑）、`⋯`（复制、删除）。
- **单击无动作**（仅悬停高亮 + 手型光标）。
- **双击连接**；已存在该主机的终端标签则切过去（按 IP:端口 去重）。
- 右键：连接、编辑、复制、删除。

**工具条**：标题 + 数量；搜索框；「新建主机」。

**空状态**：图标 + 「还没有主机」+「添加主机」。

**0.1.0 现状**：卡片、搜索、编辑抽屉、删除、双击开终端已可用；状态点、`⋯` 菜单、卡片右键菜单、复制主机尚未做（卡片上只有编辑与删除两个按钮）。

### 3.3 编辑抽屉

- 右侧滑入，宽 380pt，覆盖内容区；`Esc` 关闭；未保存时二次确认。
- 字段：名称、地址、端口（22）、用户名、认证方式（密码 / 密钥）、密码或 Keychain 条目、分组、备注。
- 底部：取消 / 测试连接 / 保存。
- 编辑已有主机走 `updateHost`（修现有 bug）。
- **0.1.0 现状**：抽屉宽 380pt，字段含名称 / 地址 / 端口 / 用户名 / 认证方式 / 密钥路径或密码 / 分组 / 备注；「测试连接」、`Esc` 关闭、未保存确认、从 Keychain 条目选择尚未做。

### 3.4 Keychain

- 列表：Label、类型（解析自私钥）、公钥前缀、被引用主机数、操作（编辑 / 复制公钥 / 删除）。
- 表单：**Label / Private Key / Public Key**（D10）+「从文件导入」自动填充。
- 校验：私钥可解析；公私钥不一致给警告但不阻断。
- 删除被引用的密钥时提示受影响主机。
- **0.1.0 现状**：三字段 + 从文件导入、列表显示解析出的密钥类型（OpenSSH / RSA / ECDSA）已可用；引用计数、一致性校验、编辑抽屉尚未做，条目存放于 localStorage。

### 3.5 Snippets / Logs

居中空状态：图标 + 一句话 + 灰字「一期暂不提供」。

## 4. 标签与连接模型

| 规则 | 说明 |
|---|---|
| SFTP 页 | 常驻；同一时刻只绑定一台主机；断开后回空状态 |
| 连接标签 | 每个主机一个，内容是 SSH 终端；双击主机卡片即打开/切过去 |
| 文件浏览 | 只在 SFTP 常驻页；它绑定一台主机，不随连接标签变化 |
| 连接复用 | 终端使用**独立 SSH 连接**（libssh2 阻塞读会锁会话，不能和 SFTP 共用） |
| 关闭标签 | 该主机无其它标签使用时才断开连接 |
| 本地路径 | 全局共享一条（跨标签一致） |
| 远端路径 | 每个文件页独立记忆 |
| 终端初始目录 | 新建终端时 `cd` 到该主机最近访问的远端路径 |

**0.1.0 现状**

- 标签标识为 `term-<地址>:<端口>`，同一 IP:端口只保留一个终端标签，重复双击只切换、不重连。
- 终端会话缓存在前端 store：切走标签只卸载 xterm 实例，shell 继续运行，输出最多保留 512KB 并在切回时重放。
- SFTP 与终端各用各的 SSH 会话，互不复用；SFTP 断开不影响终端。
- 「关闭标签即断开该 shell」已实现；「无其它使用者才断开」「终端初始目录 cd」尚未实现。

### 5.2 右键菜单

| 菜单项 | 本地栏 | 远端栏 | 快捷键 |
|---|---|---|---|
| 拷贝到远端 / 拷贝到本地 | ✓ | ✓ | `⌥⌘C` |
| 刷新 | ✓ | ✓ | `⌘R` |
| 在 Finder 中显示 | ✓ | × | — |
| 复制路径 | ✓ | ✓ | `⌥⌘P` |
| 新建文件夹 | × | ✓ | `⇧⌘N` |

- 本地栏不提供任何写操作（D5），改文件一律用 Finder。
- 菜单分组：拷贝 / 刷新 一组，刷新之后是「在 Finder 中显示 / 复制路径」，删除单独一组（红色）。
- 只读卷 / 无权限目录：对应菜单项置灰并给出原因。
- 远端删除不可恢复：二次确认并显示项数；删除目录时递归删除并确认。

### 5.3 拷贝冲突（D14）

**触发**：拷贝到对侧时目标目录已存在同名项。

**流程**

1. **预检优先**：传输开始前扫描全部冲突项，收集成一个列表，不逐个弹窗。
2. 弹窗标题「N 个项目已存在」，列表每行：文件名、源/目标的大小与修改时间对比。
3. 每个文件可选：**覆盖 / 新建副本 / 跳过**。
4. 文件夹额外提供：**合并**（递归应用同一策略）。
5. 底部「对全部应用」开关（默认关）。
6. 「新建副本」命名：`name 2.ext`，已存在则递增 `name 3.ext`。
7. 取消 = 全部不传；已在进行中的其它任务不受影响。

## 6. 核心流程

**F1 首次使用**：Home → 添加主机 → 测试连接 → 保存 → 双击卡片 → 打开该主机的 SSH 终端标签；需要传文件时切到 SFTP 页绑定同一主机。

**F2 从 SFTP 页连**：切到 SFTP → 右栏「选择主机」→ 选中 → 右栏绑定 → 拖拽传输。

**F3 上传**：本地栏选中 → 拖到远端 / 右键「拷贝到远端」→ 队列。

**F4 下载**：远端选中 → 拖到本地 / 右键「拷贝到本地」/ ⌘D → 落到本地栏当前目录。

**F5 终端**：双击主机卡片，或从 SFTP 页头部点「终端」。

**F6 断线**：顶部横幅 → 自动重连 → 队列继续。

**0.1.0 现状**：F1 没有「测试连接」这一步（填完直接保存）；F2 只支持「选择主机」，不支持拖拽；F3 / F4 只能走右键菜单（无拖拽、无 `⌘D`）；F6 仅终端有手动「重连」，SFTP 靠手动断开重连。

## 8. 平台注意

1. TCC：本地栏默认 `~/`，避开 Desktop/Documents/Downloads 首次弹窗。
2. 外接卷 / iCloud Drive 可浏览，失败要有降级提示。
3. 拖出需原生插件（drag-rs / tauri-plugin-dragout）。
4. 先用普通表格；单目录超过 1000 项再考虑虚拟滚动。
5. 权限串用 `drwxr-xr-x` 形式，本地远端都显示。

### 8.1 规模假设（按实际使用收窄）

| 项 | 假设 | 影响 |
|---|---|---|
| 单目录条目 | ≤ 2000 | **不做虚拟滚动**，普通表格即可 |
| 单文件 | ≤ 200MB | **单通道顺序传输**，不做分片并行 |
| 并发传输 | 1–4，默认 4 | 不做动态调度 |
| 服务器配置 | 低配（CPU/内存有限），系统本身不旧 | 并发 ≤ 4、每主机 SFTP 一条连接 + 每个终端一条、默认不开压缩 |

### 8.2 算法与资源策略

服务器系统不旧，**不需要为老算法做妥协**：默认走 libssh2 的现代算法，不主动裁剪、也不主动放开旧算法。

libssh2 本身仍支持 `group1-sha1`、`aes-cbc`、`3des-cbc`、`hmac-sha1`、`ssh-rsa` 等旧算法——保留这个能力作为兜底：真遇到只提供旧算法的机器，客户端侧放开即可，不必改服务器。

低配服务器上真正要克制的是资源占用：

| 策略 | 做法 |
|---|---|
| 连接数 | 每主机 SFTP 一条 + 每个终端一条（libssh2 阻塞读不允许共用）；终端标签按 IP:端口 去重，避免重复占连接 |
| 并发传输 | 目标默认 4，低配机器可降到 2（0.1.0 仍是逐个文件串行） |
| 压缩 | 默认关闭（低配 CPU 上压缩可能得不偿失） |
| 列目录 | 不做额外的逐项 `stat`，直接用 readdir 返回的属性 |
| 心跳 | 目标 keepalive 60s，避免空闲连接被中间设备断开（0.1.0 未设置） |

| 项 | 值 |
|---|---|
| 主机 | `162.14.*.*`（腾讯云轻量，真实地址不入库） |
| 系统 / SSH | Ubuntu 24.04 / OpenSSH 9.6p1 |
| 用户 | `ubuntu`（`root` 被拒） |
| 认证 | **仅 publickey**（密码认证关闭） |
| 算法 | curve25519-sha256 / chacha20-poly1305 / ssh-ed25519 |
| 主机指纹 | SHA256 `e5e09285…45815b65` |
| 延迟 | TCP 18ms / 握手 192ms / 认证 46ms |
| SFTP | 打开 477ms / 列目录 67ms（2 项） |
| 传输 | 上传 2.0 MB/s、下载 0.46 MB/s（20MB，校验通过） |

结论：**不需要老算法兼容**；瓶颈在服务器出网带宽（约 3.7 Mbps），不在客户端。200MB 上传约 1.7 分钟、下载约 7 分钟——按「不做性能优化」处理。
